Comment installer un jeu Windows ?
  1. Ajoutez une image brute d’un disque Windows 95, 98 ou 2000, ou installez Windows sur un disque vierge.
  2. Démarrez ce PC, puis montez l’ISO du jeu avec « Changer de CD ».
  3. Dans Windows, ouvrez le lecteur CD et lancez l’installation. Les fichiers et le registre sont conservés dans le disque virtuel.
  4. Utilisez « Enregistrer et fermer » avant de quitter, puis « Sauvegarder sur Drive » pour retrouver cette installation sur un autre appareil.

La compatibilité des jeux et les performances sur Pixel restent à valider. Le moteur fournit une carte VGA/SVGA ; il ne simule pas une carte 3D moderne.
