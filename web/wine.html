Enregistre ta partie dans le jeu avant de fermer. Les fichiers sont copiés localement toutes les cinq secondes ; « Enregistrer et fermer » ferme aussi les programmes et conserve le registre. La sauvegarde Drive se lance depuis la carte du profil.

Installer et reprendre un jeu
  1. Crée un profil, puis sélectionne-le dans sa carte.
  2. Connecte Drive, ouvre le dossier du jeu et choisis « Utiliser ce CD ». Un ISO local peut aussi être ajouté depuis la carte.
  3. Ouvre le profil, actualise les programmes, puis lance le programme d’installation sur D:.
  4. Après l’installation, actualise la liste et choisis le jeu installé sur C:. Ce choix est conservé pour le prochain lancement.
  5. Enregistre ta partie, puis ferme le profil. « Sauvegarder sur Drive » crée une sauvegarde complète. Sur l’autre appareil, restaure le fichier .retroiso-wine.json.
Cette voie vise les programmes Windows x86 compatibles avec Wine. Les ISO de consoles nécessitent d’autres émulateurs. Les CD ISO 9660 / Joliet sont présentés comme des fichiers sur D: ; certaines protections CD et les images UDF seules ne sont pas prises en charge. Les performances et l’affichage sur Pixel 9a doivent encore être validés.
